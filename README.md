# recruit-crm-api

## Description

APIs written in NestJS with Express and Typescript

## Prerequisites

- Node >= v18.xx
- MySQL >= 8

## Installation

```bash
$ npm install
```

## Create .env file

```bash
$ cp .env.example .env
```

# Run TypeORM migrations

```bash
$ npm run migrate:up
```

## Running the app

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Test

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
